# Launcher artwork

The launcher looks for these files here and works without them (plain dark
background and the default window icon):

| File | Used for | Size |
|---|---|---|
| `background.jpg` | Play page hero image | 1920×1080 or larger |
| `header.jpg` | Header strip of the other pages | 1920×1080 |
| `icon.ico` / `icon.png` | Window and exe icon | 256×256 |

The images used during development are Silent Hill 3 fan art and box art
(© Konami), so they are **not** part of this repository. Put your own images
here with the same names before running `scripts/package_sh3.py`.
